# Тестовое задание инфотекс:

REST API weather_forecast

## Задание:

Реализовать REST API  сервер со следующими методами:

- Метод принимает координаты и возвращает данные о температуре, скорости ветра и атмосферном
давлении на момент запроса.
- Метод принимает название города и его координаты и добавляет в список городов, для которых
отслеживается прогноз погоды. Сервер должен хранить прогноз погоды для указанных городов на текущий
день и обновлять его каждые 15 минут.
- Метод возвращает список городов, для которых доступен прогноз погоды.
- Метод принимает название города и время и возвращает для него погоду на текущий день в указанное
время. Должна быть возможность выбирать, какие параметры погоды получать в ответе — температура,
влажность, скорость ветра, осадки.

## Реализация:

### Для первого метода был релизован GET эндпроинт **/weather/current** с query параметрами:

- **lat** latitude, float широта.
- **lon** longitude, float долгота.

Возвращает данный метод JSON с полями:
- temperature: float
- wind_speed: float
- atmospheric_pressure: float

### Для второго метода был реализован POST эндпоинт **/weather/cities** c query параметрами:

- **city** город.
- **lat** latitude, float широта.
- **lon** longitude, float долгота.

Данный метод добавляет город и его координаты в базу данных, также для этого метода была реализована фоновая задача для обновления погоды в данный момент каждые 15 минут и добавления в базу данных. В случе если город уже есть в базе данных, метод возвращает 403.
При успешном отправлении города с координатами в базу данных возвращает строку "Город успешно добавлен"

### Для третьего метода был реализован GET эндпроинт **/weather/cities**:

Данный метод берет весь столбец городов из базы данных и возвращает его в виде списка

### Для четвертого метода был реализован GET эндпроинт **/weather/city** c query параметрами:

- **city** город.
- **time** время в формате ЧЧ:ММ str.
- **temperature** температура bool.
- **humidity** влажность bool.
- **wind_speed** скорость ветра bool.
- **precipitation** осадки bool.

Данный метод находит в базе данных город с заявленным временем и возвращает те показатели погоды которые в параметрах запроса были установлены как True

## Запуск сервера:

### При запуске из архива:

- Распаковать
- Перейти в дирректорию/папку weather_forecast
- Запустить сервер командой "python3 script.py"

Сервер запустится на хосте 127.0.0.1 с портом 8000.

Также по адреесу http://127.0.0.1:8000/docs можно изучить OpenApi документацию к серверу

### При запуске из гитхаба:

- Скачать зависимости из pyproject.toml
- В дирректории/папке weather_forecast создать файл .env с переменными окружения:
    - app_name, название сервиса
    - version, версия
    - host, хост (127.0.0.1)
    - port, порт (8000)
    - debug, отладка (True/False)
    - db_path, путь к базе данных
- Перейти в дирректорию/папку weather_forecast
- Запустить сервер командой "python3 script.py"
